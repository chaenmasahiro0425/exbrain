# research/ — 検証済みリサーチ

`/brain-research <テーマ>` の出力先。**スケプティック検証を生き残った主張だけ**が、レシート（出典URL+日付）と `expires:`（賞味期限）付きで貯まる。

- 形式: [[templates/research]] 準拠。`sources: verified | single-source | rumor` を明記
- 期限切れは週次lintが検出 → 再リサーチするか削除する
- 単発のチャット回答で終わらせず、ここに残すことで次のリサーチ・記事・提案書の土台になる
