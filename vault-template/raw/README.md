# raw/ — 手動ダンプの受け皿

持っているものを何でもここに放り込む場所。**夜間compile（brain-compile.sh）が翌朝までにwiki層へ編纂する**。

- 対象: 文字起こし・チャットログ・メモアプリのエクスポート・競合調査・過去資料
- ルール: ここのファイルは**不可侵（ground truth）**。コンパイラも人間も書き換えない。編纂済みでも消さない
- 命名: `YYYY-MM-DD_<内容>.md`（できれば。無理なら何でも可）

X由来は clips/、日次の出来事は daily/ が受け皿（このフォルダは「それ以外全部」）。
